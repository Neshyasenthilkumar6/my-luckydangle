🍀 Lucky Dangle

A customizable desktop charm application developed using Python and PyQt6.

✨ Features

- 🍀 Includes multiple built-in charm designs
- 🖼️ Allows users to upload custom charm images
- 🖱️ Drag and position the charm anywhere on the desktop
- 🔄 Provides smooth swinging animations
- 📌 Supports an always-on-top desktop widget
- 🖱️ Includes a convenient right-click context menu
- 💻 Lightweight and easy-to-use desktop application

🛠️ Technologies Used

- Python
- PyQt6
- Qt GUI
- Basic physics-based animation

🚀 How to Run

Install the required dependencies using:

pip install -r requirements.txt # my-luckydangle
